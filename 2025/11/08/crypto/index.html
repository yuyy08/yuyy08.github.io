Base 系列编码原理

一. 通用编码步骤

  1. 原始数据转二进制
    将待编码的每个字符按 ASCII 码转成 8 位二进制。
  2. 重新分组
    按新的 bit 数（4、5 或 6）从左到右切分，不足时补 0。
  3. 转十进制并查表
    将每个二进制组转成十进制，作为索引查编码表得到对应字符。
  4. 处理末尾
    若最后组不足新 bit 数长度，补 0 并在编码结果末尾加 =（Base64/Base32 有填充，Base16 一般不需要）。

二. 三种编码对比

编码类型 分组 bit 数 字母表 填充字符
Base16 4 bit 0123456789ABCDEF 无
Base32 5 bit ABCDEFGHIJKLMNOPQRSTUVWXYZ234567 =
Base64 6 bit ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/ =

三. 举例说明（Base64）

字符串 “A”

· ASCII: 65 → 二进制 01000001
· 按 6 bit 分组：010000 010000（第二个组只有 2 位，补 4 个 0）
· 十进制：010000 = 16 → Q；010000 = 16 → Q
· 补了 1 组 0，所以加 2 个 =
· Base64 结果：”QQ==”
